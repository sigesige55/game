★カスタマイズの方法★

説明文を変えたい場合
HTML内の <p class="game-description"> の中身を書き換えてください。

画像を入れたい場合
ゲームフォルダに画像（例：thumb01.png）を入れ、コメントアウトされている <img ...> の部分の `` を消して有効にしてください。

リンクを増やしたい場合
<article class="game-card"> から </article> までのカタマリをコピーして増やすだけです。



★ミニゲームポータル仕様書★

1. デザインコンセプト
トーン: シンプル＆カジュアル。

配色: 白背景をベースに、清潔感のある淡いグレーや、アクセントとして親しみやすいブルーやグリーンを使用。

フォント: 読みやすさを重視したゴシック体（丸みを帯びたものなど）。

2. メンテナンス性への配慮（後からの追記方法）
画像やテキストを後日簡単に差し替えられるよう、以下の構成を提案します。

HTML構造の共通化: 各カードを同じクラス名で管理し、1箇所書き換えれば全てのデザインが整うようにします。

プレースホルダーの活用:

説明文: 「ここにゲームの説明文が入ります（追記可能）」と仮置き。

画像: 指定がない場合は、グレーの背景に「No Image」と表示される仕組み、またはダミー画像生成サービスを利用。

3. カードの詳細構成（1枚あたり）
後からの追記を前提とした、具体的なカード内要素です。

要素	ステータス	追記・変更方法
サムネイル画像	仮置き	<img>タグのパスを画像ファイル名に書き換えるだけ。
ゲームタイトル	Game 01...	<h3>タグ内を書き換え。
説明文	仮置き	<p>タグ内のテキストを自由に変更。
リンクボタン	設定済	https://sigesige55.github.io/game01/ 等をセット。

4. 技術スタック（推奨）
HTML5 / CSS3: フレームワークを使わず、軽量なコードで構築。

CSS Grid: 10枚のカードを綺麗に整列させ、スマホで見ても崩れないレスポンシブ対応を実現。




ミニゲームポータルサイト 仕様書
1. 概要
本プロジェクトは、10種類のミニゲームへアクセスするための1枚完結型（シングルページ）のポータルサイトです。ユーザーが直感的に遊びたいゲームを選択できるよう、カード形式のレイアウトを採用します。

3. 基本情報
カレントURL: https://sigesige55.github.io/game/

ターゲット: ブラウザゲーム利用者

ページ構成: 1枚構成（レスポンシブ対応）

3. 画面構成要素
3.1 ヘッダー
タイトル: 例：「Mini Game Collection」

概要文: 10種類のミニゲームを無料で遊べるポータルサイトである旨を記載。

3.2 ゲームカードエリア（メイン）
各ゲームを以下の要素を含む「カード」として計10枚表示します。

項目,内容,リンク先例
タイトル,ゲームタイトル（Game 01 〜 Game 10）,-
説明文,各ゲームの内容を簡潔に説明（1〜2行程度）,-
ボタン,「このゲームで遊ぶ」などのCTAボタン,https://sigesige55.github.io/game01/

3.3 フッター
著作権表示（例：© 2026 sigesige55）

4. 技術仕様
レイアウト: CSS Grid または Flexbox を使用したレスポンシブデザイン（PCでは3〜4列、スマホでは1〜2列）。

ホバーエフェクト: マウスホバー時にカードが少し浮き上がる、または色が変化するインタラクション。
